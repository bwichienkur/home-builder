# Olsen Inventory Images + Master Catalog

This package contains the latest consolidated master catalog plus the individual product/reference images extracted from the Olsen Look Book.

## Folders
- `inventory_images/` — individual extracted product images, grouped by catalog category.
- `lookbook_reference_pages/` — full-page reference renders for checking labels/finish relationships.
- `Olsen_3D_Full_Master_Catalog_Updated.xlsx` — current consolidated inventory/catalog workbook.
- `inventory_image_manifest.csv` — maps each extracted image to Look Book page/category and nearby text.

## Important
The extracted inventory images are source/reference images from the Olsen Look Book. Some pages contain multiple finish views, swatches, or product-detail images, so these are candidates rather than a claim that every file is a unique SKU. Use the master catalog to normalize geometry families and variants. Manufacturer imagery can replace these reference crops later where licensing/use permits.
